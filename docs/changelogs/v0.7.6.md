# Changelog v0.7.6

All notable changes to kprun are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.7.6] - 2026-11-12

### Changed

- Dependency updates: ureq 3.5.0 → 3.5.2 (pulls ureq-proto 0.7.1); GitHub Actions taiki-e/install-action 2.90.3 and softprops/action-gh-release 3.0.4. Supersedes the open dependabot PRs #118, #119 and #120.

### Fixed

- `kprun mcp` no longer rejects an upstream JSON response whose body is exactly 10 MiB (the read limit); fixed by ureq 3.5.2. Larger responses are still refused with a JSON-RPC error and the bridge keeps running.
- Improved HTTP connection reuse and chunked transfer-encoding handling (ureq-proto 0.7.1) and a fix for reading responses after macOS rejects socket timeout changes (ureq 3.5.1).

### Tests

- New `kprun mcp` integration tests pin: no `Cookie` header is ever sent, chunked JSON responses keep keep-alive connections reusable, and the 10 MiB body-limit boundary.
