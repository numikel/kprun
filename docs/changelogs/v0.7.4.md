# Changelog v0.7.4

All notable changes to kprun are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.7.4] - 2026-10-25

### Changed

- Dependency updates (`cargo update`), superseding the open dependabot PRs for rand, which, sha2, zeroize, serde.

### Security

- rustls-webpki 0.103.16 (RUSTSEC-2026-0382), webpki-roots and webpki-root-certs 1.0.11 (RUSTSEC-2026-0381, -0383), ctutils 0.4.5 (RUSTSEC-2026-0385). v0.7.3 shipped with the vulnerable versions; upgrade to 0.7.4.
