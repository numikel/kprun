# Changelog v0.7.2

All notable changes to kprun are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.7.2] - 2026-09-25

### Changed

- Dependency updates: keepass (→0.13.25), ureq (→3.4.2), clap (→4.6.7), thiserror (→2.0.21);
  GitHub Actions taiki-e/install-action (→2.87.20), dorny/paths-filter (→4.0.3),
  softprops/action-gh-release (→3.0.3) and Swatinem/rust-cache. No change to kprun's behavior.
- keyring stays on 4.1.5: 4.1.6+ replaces the concrete cause shown when no OS keychain is
  available (e.g. "no secret service provider or dbus session found") with a generic message.
- New regression tests pinning user-visible behavior across dependency bumps: exact error
  messages, `--help` output of every command, usage exit codes, `run` argument passthrough,
  MCP bridge transport behavior (legacy fallback, timeouts, chunked SSE, keep-alive), and a
  golden vault written by kprun 0.7.1 that must keep reading back identically.

### Security

- rustls (→0.23.45) fixes RUSTSEC-2026-0285 (TLS 1.3 handshake messages accepted across
  encryption level boundaries), used by `kprun mcp` for HTTPS connections.
